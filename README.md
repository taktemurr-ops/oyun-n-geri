# Geri Hafıza · N-Back

Aynı yer birkaç adım önce de yandı mı?

Izgarada her adımda bir kare yanar. Yanan kare N adım önce yanan kareyle aynıysa “Aynı!” düğmesine bas; değilse bekle. N, zorlukla 1’den 3’e çıkar. Yüzde 75 isabetle bölümü geç.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Zihin Antrenmanı merkez uygulamasının oyunu; ortak motor: [zihin-motoru](https://github.com/taktemurr-ops/zihin-motoru).
